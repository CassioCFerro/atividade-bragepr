# Propósito do Projeto

O propósito deste projeto é desenvolver um sistema ágil e intuitivo para o gerenciamento de chamados de suporte técnico (Help Desk). A aplicação tem como objetivo centralizar e organizar as solicitações de assistência, facilitando a comunicação entre os usuários que reportam os problemas e a equipe técnica responsável pela resolução. Com isso, busca-se reduzir o tempo de resposta, melhorar o acompanhamento do status dos chamados e aumentar a satisfação geral dos usuários.
